# Disable LLM Configuration

## Purpose

Prevents an LLM Configuration from being selected by new AI Tasks.

Existing executions are not affected.

---

## Trigger

More

↓

Disable

---

## Confirmation

```text
Disable this configuration?

Existing AI Tasks will continue working.

New tasks cannot select this configuration.

[Cancel]     [Disable]
```

---

## Success

- Status changes to Disabled.
- List refreshes.
- Success notification is displayed.
