# Preparation Plan

## Purpose

The Preparation Plan section shows the generated **preparation plan** for an application:
a curated set of hard-skill and soft-skill recommendations ("what to learn / what to
improve, why, and how to practice") derived from the gap between the job analysis and the
candidate profile. The plan is generated by the AI workflow
(`application_preparation` execution) and read from
`GET /api/applications/by-job/{id}` (`preparation`).

## Component Hierarchy

```text
PreparationPlan
├── Section header        ⚡ icon + title + [Generate]/[Regenerate]
├── Version/date line     version · generated at
├── Hard skills grid      HardSkillCard per recommendation
└── Soft skills grid      SoftSkillCard per recommendation
```

## Behaviors

| Element | Behavior |
| ------- | -------- |
| Generate | No plan yet → `[⚡ Generate]`. Sends `POST /api/applications/{id}/preparation/generate` (202). SSE progress + refetch on completion. |
| Regenerate | Plan exists → button becomes `[⚡ Regenerate]`; queues a new version. |
| Gap level tag | `missing` / `low` / `matching` rendered next to each skill. |
| Priority tag | `high` (red) / `medium` (amber) / `low` (blue) when present. |
| HardSkillCard | skill · gap · priority · why · **What to learn** · **How to practice** · **Resources** · estimated effort. |
| SoftSkillCard | skill · gap · priority · why · **What to improve** · **How to practice**. |

## Empty States

```text
PREPARATION  [⚡ Generate]
  No preparation plan yet. Generate a tailored skill plan from the
  job analysis and your profile.
```

- A plan with no recommendations renders "This plan has no recommendations yet."

## Generating State

- While `generating` and no plan: button shows spinner, helper text "Generating your
  preparation plan…".
- Full workflow progress (current step + %) is shown by the page-level
  `GenerationProgress` SSE card.
