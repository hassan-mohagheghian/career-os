# Sprint 15 — Decommission the Insights Module

## ROLE

You are a Principal Software Architect, DDD Expert, FastAPI Expert, Frontend Architect, Database Architect, LangGraph Expert, and Software Refactoring Specialist.

Your task is to completely remove the current Insights feature from the system.

This is a feature decommissioning sprint.

The goal is to remove the existing implementation cleanly while keeping the architecture healthy and ready for a future redesign.

Business functionality unrelated to Insights must remain unchanged.

--------------------------------------------------
CONTEXT
--------------------------------------------------

The current system contains an Insights feature.

It currently includes analyses such as:

- Opportunities
- Companies
- Skills
- Market
- Networking / Connections
- Communication

These analyses were previously generated by AI workflows.

The feature will be redesigned in the future.

For now, it should be completely removed.

--------------------------------------------------
OBJECTIVES
--------------------------------------------------

Remove the entire Insights feature.

Do NOT leave partially unused code.

Do NOT keep dead APIs.

Do NOT keep unused database tables.

Do NOT keep unused frontend pages.

The system should behave as if Insights never existed.

--------------------------------------------------
BACKEND
--------------------------------------------------

Remove:

- Insights bounded context
- Application services
- Domain models
- Repositories
- Commands
- Queries
- DTOs
- Validators
- Background jobs
- ARQ tasks
- LangGraph workflows
- LangChain prompts
- Tool integrations
- Events
- Dependency injection registrations

Review the project for every remaining reference.

--------------------------------------------------
DATABASE
--------------------------------------------------

Review the schema.

Remove:

- Insights tables
- Insights columns
- Foreign keys
- Junction tables
- Indexes
- Constraints

Create Alembic migrations.

Migration must preserve unrelated data.

--------------------------------------------------
FRONTEND
--------------------------------------------------

Remove:

- Insights pages
- Routes
- Navigation entries
- Sidebar items
- Components
- Hooks
- Stores
- API clients
- WebSocket subscriptions
- Status badges
- Icons
- Menus

The UI should contain no visible reference to Insights.

--------------------------------------------------

Do NOT implement the new Insights architecture.

Instead:

Leave the surrounding architecture clean and ready so that a future implementation can introduce a completely redesigned Insights module without compatibility constraints.
