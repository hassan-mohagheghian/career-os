"score" = FIT letter grade → Use FIT rules ONLY

The numeric representation of "score". Use the numeric scale below.

"success" = SUCCESS letter grade → Use SUCCESS rules ONLY
What is the probability of actually getting hired? Consider visa, competition, company, logistics, and application strategy.
Ignore: technical stack, programming languages, backend experience.

"success_score" = SUCCESS numeric score (0-100 integer) → Use SUCCESS rules ONLY
The numeric representation of "success". Use the numeric scale below.
This is the SUCCESS PROBABILITY score.

"action" = Derive from both scores:
- score=A++ or A+ AND success=A+ or A++ → "Apply Now"
- score=A or B AND success=B or better → "Apply Soon"
- score=C or better AND success=C or better → "Consider"
- Otherwise → "Skip"

"apply_reason" = A concise 1-2 sentence explanation of WHY the candidate should apply or skip. Reference specific strengths (tech stack match, visa clarity, salary) or weaknesses (wrong stack, too many applicants, German required). This is the decision-making summary.

"notes" = Explain reasoning using at least 2 specific rules.

Grade scale (letter grades for "score" and "success"):

- "C" = Moderate / Possible
- "B" = Good / Good chance
- "A" = Great / Strong chance
- "A+" = Excellent / Very strong chance
- "A++" = Perfect / Almost certain

Numeric scale (for "fit_score" and "success_score"):
- 0-29 = D (Poor)
- 30-49 = C (Moderate)
- 50-69 = B (Good)
- 70-79 = A (Great)
- 80-89 = A+ (Excellent)
- 90-100 = A++ (Perfect)
