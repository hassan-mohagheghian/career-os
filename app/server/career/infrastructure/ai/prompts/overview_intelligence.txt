Analyze the candidate's career position and generate an Overview Intelligence Report.

Read the jobs database at {project_root}/server/db/jobs.db.
Tables available:
- jobs (deleted=0): company, role, location, score, match, fit_score, success_score, overall_score, stack, visa, work_type, employment_type
- companies: name, industry, company_type, country, city, tech_stack, funding_stage, company_size
- company_intelligence: company_id, overview, visa_analysis, technology_analysis, scores
- tech_stack: name, level, roles, path

Generate an overview report as JSON and save to {tmp_dir}/overview_intelligence_{pid}.json with this structure:

{{
  "position": {{
    "totalJobs": <number>,
    "highMatchJobs": <number>,
    "applyNowJobs": <number>,
    "visaFriendlyCompanies": <number>,
    "targetCompanies": <number>,
    "skillMatchPercentage": <number 0-100>,
    "biggestSkillGaps": ["<skill1>", "<skill2>", "<skill3>"]
  }},
  "careerHealthScore": {{
    "overall": <number 0-100>,
    "breakdown": {{
      "jobMarketFit": <number 0-100>,
      "companyFit": <number 0-100>,
      "visaProbability": <number 0-100>,
      "skillAlignment": <number 0-100>,
      "networkingStatus": <number 0-100>
    }}
  }},
  "nextActions": [
    {{
      "priority": 1,
      "action": "<specific actionable recommendation>",
      "reason": "<why this matters>",
      "impact": "high|medium|low"
    }}
  ]
}}

RULES:
- Calculate career health score based on: job market fit (score distribution), company fit (visa-friendly companies), visa probability (visa ratings), skill alignment (skills match %), networking status (0 if no data, 50 if companies exist, 80+ if active networking)
- nextActions: Generate 3-5 prioritized actions based on actual data
- biggestSkillGaps: Top 3 skills that appear in 30%+ jobs but candidate lacks
- Be evidence-based. Reference actual job counts and company data.
- Consider European software engineering markets, especially Germany and Netherlands.
- Output ONLY valid JSON. No markdown, no explanation, no code fences.
