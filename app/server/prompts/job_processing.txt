CRITICAL LOCATION RULES:
- "location" must be ONLY the primary city name (e.g., "Berlin", "Munich", "Hamburg")
- "locations" must be an array of ONLY city names (e.g., ["Berlin", "Munich", "Remote"])
- Do NOT include country names in locations unless the job is country-wide (e.g., "Germany" for fully remote)
- Do NOT include region/state names (e.g., NOT "Bavaria", NOT "Bayern")

- For remote jobs, use "Remote" as one location if no specific city

CRITICAL EMPLOYMENT TYPE RULES:
- "employment_type" must be exactly ONE of: "Full-time", "Part-time", "Contract", "Internship", or "Temporary"

- "Part-time" is explicitly part-time or reduced hours
- "Internship" is for students or entry-level temporary positions
- "Temporary" is fixed-term or project-based

CRITICAL WORK_TYPES RULES:
- "work_types" must be an ARRAY of work arrangements (can have multiple)
- Each item must be exactly: "On-site", "Remote", or "Hybrid"
- A job can be both "Hybrid" and "Remote" if it offers flexibility
- Default to ["On-site"] if not specified
- Extract from job posting text, NOT from location
