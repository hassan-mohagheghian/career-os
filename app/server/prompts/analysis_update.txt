RULES FOR overview:
- Count jobs requiring Python, TypeScript, and other key skills
- Calculate average score from all jobs
- List top 5 most in-demand skills

RULES FOR strategy:
- 5-6 items, specific to actual job data (name companies, give counts)
- Include visa strategy, application timing, and Python advantage

RULES FOR strengths:
- Only include skills Hassan actually has with evidence from job requirements
- Reference specific job counts and companies

RULES FOR weaknesses:
- Skills that appear in multiple jobs but Hassan lacks
- Include count of jobs requiring each skill

RULES FOR visa_companies:
- Companies with BEST or Strong visa rating from processed jobs
- Include why each company is good for visa

RULES FOR apply_urgency:
- Jobs scored 75+ or posted recently that need immediate action
- Include applicant counts when available

RULES FOR techStack:
- level: 1-5 based on Hassan's current proficiency (5=expert, 1=beginner)
- roles: percentage of jobs where this skill applies
- path: learning or maintenance recommendation

RULES FOR techLearning:
- Only include technologies that appear in actual job postings
- priority: 1=critical (appears in 30%+ jobs), 2=important (15-30%), 3=useful (5-15%)
- usage: percentage of jobs requiring this skill
- jobs: fraction like "9/20" showing how many jobs need it
- reason: explain why Hassan should learn this (based on job data)
- action: specific learning recommendation

RULES FOR skillJobFit:
- For each of Hassan's skills, calculate what percentage of jobs require it
- fitScore: 0-100 based on skill proficiency × job relevance
- Include specific companies that need each skill

RULES FOR learningROI:
- For skills Hassan doesn't have, calculate learning ROI
- impactScore: 1-10 based on number of jobs unlocked
- timeToLearn: estimated time to reach usable proficiency
- Sort by impactScore descending

RULES FOR cities:
- Count jobs per city from job data
- Include top companies in each city
- Sort by job count descending

Use ONLY data from actual processed jobs. Include specific numbers and company examples.
