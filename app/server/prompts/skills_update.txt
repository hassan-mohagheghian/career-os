RULES FOR techLearning:
- Only include technologies that appear in actual job postings
- priority: 1=critical (appears in 30%+ jobs), 2=important (15-30%), 3=useful (5-15%)
- usage: percentage of jobs requiring this skill
- jobs: fraction like "9/20" showing how many jobs need it
- reason: explain why Hassan should learn this (based on job data)
- action: specific learning recommendation

RULES FOR techStack:
- level: 1-5 based on Hassan's current proficiency (5=expert, 1=beginner)
- roles: percentage of jobs where this skill applies
- path: learning or maintenance recommendation

RULES FOR learningPriorities:
- Top 5 skills Hassan should learn next, with data-backed reasons

RULES FOR skillGaps:
- Skills that appear in jobs but Hassan lacks
- Include count of jobs requiring each skill

Use ONLY data from actual processed jobs. Include specific numbers and company examples.
