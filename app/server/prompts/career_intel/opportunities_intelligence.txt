Analyze processed jobs to generate an Opportunities Intelligence Report.

Read the jobs database at {project_root}/server/db/jobs.db.
Tables available:
- jobs (deleted=0): company, role, location, score, match, fit_score, success_score, overall_score, stack, visa, work_type, employment_type, posted, applicants
- companies: name, industry, company_type, country, city

Generate an opportunities report as JSON and save to {tmp_dir}/opportunities_intelligence_{pid}.json with this structure:

{{
  "funnel": {{
    "applyNow": [{{"num": <job_num>, "company": "<name>", "role": "<title>", "location": "<city>", "overallScore": <number>, "freshness": "<new|recent|older>", "visaProbability": "<BEST|Strong|Good>", "skillMatch": <number 0-100>}}],
    "highPotential": [...],
    "consider": [...],
    "lowPriority": [...]
  }},
  "insights": [
    {{"observation": "...", "evidence": "...", "action": "..."}}
  ],
  "bestJobsThisWeek": [...],
  "missedOpportunities": [...],
  "multiRoleCompanies": [{{"company": "<name>", "roles": [...], "count": <number>}}]
}}

RULES:
- applyNow: overall_score >= 80
- highPotential: overall_score 65-79
- consider: overall_score 50-64
- lowPriority: overall_score < 50
- freshness: "new" if posted this week, "recent" if this month, "older" otherwise
- missedOpportunities: Jobs scored A+ or above that are older than 2 weeks
- multiRoleCompanies: Companies with 2+ open roles matching candidate profile
- Be evidence-based. Reference actual job data.
- Consider European software engineering markets, especially Germany and Netherlands.
- Output ONLY valid JSON. No markdown, no explanation, no code fences.
