# Feature: Career Intelligence System

## Goal

Build a lightweight but powerful Career Intelligence module that analyzes the candidate profile, jobs, companies, skills, market data, and networking opportunities.

The goal is not to create heavy analytics. The goal is to provide actionable insights that help the candidate reach a visa-sponsored backend engineering role in Germany or Netherlands faster.

The system should analyze:

- Candidate profile and uploaded resume/LinkedIn data
- Processed jobs
- Processed companies
- Company-job relationships
- Scoring results
- Skills extracted from jobs
- Market information
- Networking opportunities

The output should answer:

"What is my current position, what opportunities are best, what should I do next, and what should I learn?"

---

# Information Architecture

Create a new main menu:

Career Intelligence

Use these sections:

1. Overview
2. Opportunities
3. Companies
4. Skills
5. Market
6. Networking


Avoid creating too many separate dashboards.
Each section should provide focused actionable insights.

Fields:

- id
- insight_type
- version
- status
- started_at
- completed_at
- error_message
- metadata

insight_type:

- overview
- opportunities
- companies
- skills
- market
- networking


Status:

- pending
- queued
- processing

- failed

Fields:

- id
- insight_type
- version
- score
- summary
- data_json

# Processing Workflow

Every insight generation should have a workflow.

Example:

Overview Analysis:

pending

↓

queued

↓

collecting data

↓

AI analysis

↓

calculating metrics

↓

saving results

↓

completed

Each section must have independent refresh.

Buttons:

Overview Refresh

Companies Refresh

Skills Refresh

Also provide:

Refresh All

---

# Performance Requirements

Avoid heavy database queries.

Use:

- Cached results
- Background jobs
- Incremental updates
- Versioned insights


AI calls should receive summarized structured data instead of raw database dumps.

# Final Goal

The system should continuously answer:

1. Where am I now?
2. Which jobs should I apply to?
3. Which companies should I target?
4. Which skills increase my chances fastest?
5. Who should I network with?
6. What should I do this week?

Build the feature with a scalable architecture that supports future intelligence modules.
